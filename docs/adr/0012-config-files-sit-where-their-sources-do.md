# Config files sit where their Sources do, and one that cannot be used is a row

Sources are added, and put in order, by a file named `.agentdocs.toml` in two places — the home directory, for global Sources, and a project's root, for that project's — so that which Scope a row belongs to, and which directory its relative path is taken from, are both said by where the file lies, and a repository carries its own layout wherever under the home directory it is cloned or moved — outside it there is no project block to carry it to ([ADR-0004](0004-project-root-marker-then-cwd.md)); the cost accepted is two files where one would do, and that a repository somebody else wrote can add Sources to its own block — Markdown that is read and shown, never run.

**Rejected: one file for the whole machine.** With a scope written on each row, every project row shows in every project: the layouts of two projects on this machine put three `(missing)` rows into every other one. With project rows filed under the project's path, a copy of the repository at another path, or the same directory spelled in another case, gets none of its rows and is told nothing — exit 0. Both were built and run before the choice, beside this one; the outputs are in the [M10 log](../learn/milestones/M10.md).

**A file that cannot be used is a row, and nothing in it is used.** One that will not read, does not parse, holds a key that has no place in it, or orders a Source its scope does not have adds no Sources and changes no order. A row named after the file stands at the end of its scope, where its Sources would have been, and what stopped it — the parser's own words, with the line it stopped at, or the name an `order` could not find — is printed under the row in the listing and shown in the preview when the row is selected, as [ADR-0009](0009-unreadable-is-a-row-where-it-was-found.md) shows what a Walk could not read; a file that will not read is given its reason in the program's own words, as a Walk's is. A key with no place is refused rather than passed over because `[[sources]]`, one letter too many, would otherwise add nothing and say nothing. Two other ways were run: refusing to start, with exit 2 and no screen, makes one typo cost the whole program; keeping the rows that parse loses the line and column a parse error points at, and a file that is not TOML at all is dropped whole either way.

**Order is by name.** `order` names Sources of the file's scope — the built-in ones as well as the file's own — to show first, in the order named; every other Source keeps its place after them. Naming one the scope does not have makes the file unusable, like any other mistake in it.
