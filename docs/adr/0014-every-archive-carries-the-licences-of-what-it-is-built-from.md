# Every release archive carries the licences of what its binary is built from

Every release archive carries `THIRD-PARTY-LICENSES.txt` — the licence of each crate the binaries are built from, read from that crate's own file, and those of the Rust standard library, of musl and of the syntax definitions syntect embeds — written by cargo-about from `about.toml` and `about.hbs` when a release is made, and on every push, because most of those crates are under terms that ask for their notice to go with every copy of a binary whichever of their licences is chosen; the cost accepted is a file the install scripts leave behind, since they copy only the binary, as they leave agentdocs' own licences, and a clarification in `about.toml` to keep up for each crate whose licence cargo-about does not read from a file of its own.

This adds to what [ADR-0013](0013-releases-come-from-a-tag-and-the-installers-are-tried-first.md) says an archive holds (*"the binary, the README and both licences"*). The rest of that record still holds, and the file is not an asset of the release beside the archives.

**Read from a file, or the release stops.** For a crate whose licence it finds in no file, cargo-about gives the licence's standard text — for MIT, `Copyright (c) <year> <copyright holders>` — and exits 0, and it does the same, with a warning, when a clarification no longer applies. `about.hbs` marks every text that came from no file, and `.github/third-party-licenses.sh` fails on the mark and on anything cargo-about says on stderr. CI runs it on every push, so a dependency that brings a licence it cannot read stops there, not at a release. The crates that only run while the binary is compiled are listed with the rest: more than the terms ask for, and nothing to filter.

**What is not a crate is copied by hand.** No tool lists what is linked or embedded besides crates, so `about.hbs` holds, as they were published, the MIT licence of the Rust standard library, musl's `COPYRIGHT` for the Linux binaries, and the licence of Sublime Text's Packages with the three syntax files there that carry their own. Their versions — musl as Rust ships it, Packages at the commit syntect pins — are followed by whoever changes either.

Two alternatives were measured and set aside. **Nothing**, which is what herdr, ripgrep, bat, uv and eza ship for their crates: common, and not what the terms say. **A `--licenses` flag** printing the same text from the binary, the one way the notices would survive the install scripts: it puts the text in every binary, and makes one more word on the command line mean something other than a search ([ADR-0008](0008-screen-for-a-bare-command-at-a-terminal.md)) — a flag can be added beside the file later, and taken away only by breaking what it promised.
