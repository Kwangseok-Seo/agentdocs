# A project's Sources are every Markdown file below its root, less what its `.gitignore` files leave out

The project block is two Sources — `root md`, every Markdown file below the project's root by a tree Walk, and `.claude`, the root's `.claude/` walked the same way — in place of the root's own files and `docs/`, and every Walk passes over what the `.gitignore` files it meets on its way down leave out, because a project's documentation is written wherever its work puts it — a directory per experiment, a run's summary beside its output — rather than only in `docs/`, while what a repository keeps out of git is mostly what it builds, installs or generates; the cost accepted is that a file kept out of git on purpose is not shown, that the `docs` row is gone, so a config file whose `order` names it is now unusable, and that a project root below its repository's top is walked without the top's rules.

This replaces the list of project sources in [ADR-0002](0002-discovery-global-always-project-follows-cwd.md) (`docs/`, `.claude/skills`, root-level Markdown), and the first sentence of the paragraph on what is watched in [ADR-0011](0011-changes-are-heard-not-polled.md). The counts on this machine, before and after, are in the [M12 log](../learn/milestones/M12.md).

**`docs/` is not kept as a Source of its own.** Beside a tree from the root, every file in it would be listed twice; taken out of the root's tree, the root's row would under-report the directory it names, which [ADR-0005](0005-sources-report-their-own-directory.md) rejects. A Walk still passes over a directory named with a dot, and `.claude/` is the one of those that holds agent documentation, so it is the second Source.

**Only the `.gitignore` files met on the way down are read** — the one in the directory a Walk was asked to read, and one in each directory it goes down into; the nearest with a line that matches decides, and a directory left out is not opened. Git reads upward to the repository's top, and that is rejected here for two reasons. Most of the repositories on this machine keep `.claude/` out of git whole, and what is in it is agent documentation all the same. And a home kept in git with a `*`, which leaves out whatever it does not name, would empty every global Source without a word. Neither `.git/info/exclude` nor a user's own excludes are read: what one person keeps out on one machine is not the project's statement. A `.gitignore` that will not read, or a line of one that is not a pattern, hides nothing.

**Rejected: every Markdown file, ignored or not.** One repository's row went from one file to thousands, nearly all of them a benchmark's generated results, and a Python environment's packages put their READMEs among a project's documents. Listing those was not the harm — they fold away under one directory row — but every one of them is read in full at every start and every change, and searched.

**Each directory a Walk read is watched alone**, in place of a descending Walk's directory watched with everything below it. Watched whole, a tree from a project's root takes in `.git/` and every ignored build directory, which change at every commit and every build, each change having every Source read again; and on Linux a watch below is one watch per directory, tens of thousands in one repository here. What a Walk read is what can change what it shows. A directory that appears is heard from the one that holds it, and is watched once the Walks have read it again — before the screen waits for anything else, or a file written into it next would go unheard.
