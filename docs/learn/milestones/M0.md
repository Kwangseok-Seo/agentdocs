# M0 — Project skeleton

> Roadmap: M0

## What was done

`cargo init` produced the package; metadata (description, license, keywords, categories) was filled in, and the project was dual-licensed MIT OR Apache-2.0 following the Rust ecosystem convention. `cargo run` prints `Hello, world!` and exits 0.

Four decisions that shape the roadmap were settled before any code was written. Three became ADR-0001 through 0003 — read-only viewing, the discovery rule, and the source table. The fourth, when the TUI arrives, is a roadmap ordering rather than a decision that is expensive to reverse, so it is fixed in the README and CLAUDE.md instead of an ADR.

## Concepts picked up here

- `cargo` is build tool, package manager, and test runner in one — `go build` + `go mod` + `go test` combined.
- `Cargo.toml` is the manifest a human writes; `Cargo.lock` is the machine's, and for a binary project it **is committed**.
- `edition = "2024"` is a Rust-specific idea: a **language edition** that lets the syntax move forward without breaking older code.
- `rust-version` pins the minimum supported toolchain (MSRV). The 2024 edition needs 1.85 or newer.
