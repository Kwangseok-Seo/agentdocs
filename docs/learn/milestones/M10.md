# M10 — Config files

> Roadmap: M10

## What was done

A file named `.agentdocs.toml` adds Sources of your own, and sets the order the Sources are shown in. The one in the home directory speaks for the global block; the one at a project's root, for that project's block. Neither has to exist, and with neither the program prints, byte for byte, what M9 printed.

`session-seal` keeps its documentation in `Sessions/` and `Wiki/`, which no built-in Source names; M1 found it a project with nothing to show, and the logs have carried that since — with a gap that M6 found and closed. A copy of it with this file at its root —

```toml
# This repository keeps its documentation in two directories of its own.
order = ["Wiki"]             # shown first; every other source keeps its place

[[source]]
name = "Sessions"
path = "Sessions"            # from the project's root; ~/… is from your home directory
walk = "markdown-tree"       # every Markdown file below it, directories and all

[[source]]
name = "Wiki"
path = "Wiki"
walk = "markdown-files"      # one level of Markdown files
```

— lists them, `Wiki` first:

```
$ cd session-seal && agentdocs | more        # abridged: a copy of session-seal with that file, 365 lines in all

  commands:1
```

A file that cannot be used — it will not read, it is not TOML, it holds a key that has no place in it, or its `order` names a Source that is not there — adds nothing and changes no order. ## Pitfalls actually hit

All of them the assistant's, while writing the code; each is written up where the concept lives:

- [[closures]]: `scope`, captured by the closure that makes a Source of each row, moved out on the first call — E0507. `Scope` derives `Copy` now.
- [[error-types]] and [[option-and-match]]: the third `Problem`, `Order`, stopped the build at the one `match` that then had to give it a word — E0004, which is the check doing its work. Two more `match`es name every variant now, since a file that will not read stopped being shown in the system's words.
- [[testing]]: two tests given one fixture directory, failing only together; and a stable sort whose unstable replacement passed every test until a hundred Sources were sorted.
- **The system's words, against a rule this wiki had already written down.** Slice 2 printed under a file that would not read what the system said about it, as it prints what the parser says. [[result-and-errors]] had settled in M3 that the system's words come in the machine's language — `액세스가 거부되었습니다.` here — and that the program says why in words of its own. The test written for it passed because the failure it used, a file that is not UTF-8, is worded by Rust in English. Found while writing [[error-types]], and put back: such a file is `(unreadable)`, `(permission denied)` and no more in the listing, and `(this could not be read: unreadable)` in the preview, as a Walk's would be. Written up in [[result-and-errors]].

## What measurement changed

**Where documentation lives that the defaults miss.** Before any code, every project under `~/projects` was counted for Markdown outside its root and its `docs/`: `session-seal` 330, in `Sessions/` and `Wiki/`; `skills` 34 and `cli-printing-press` 27, in a `skills/` of their own; `agent-guideline` 53, in `routines/`, `anti-patterns/` and four directories of `.claude/`; four trading projects 164 between them, in `.claude/workflows`. Outside the projects, nothing: `~/.gemini`, `~/.copilot` and `~/.config` hold no Markdown at all. Most of what a config file would add is one project's own layout.

**Where the files are.** Three ways were built into one prototype and run against this machine before the author chose:

| run in | one file, a scope on each row | a file at home and one in the repository | one file, project rows under the project's path |
|---|---|---|---|
| `session-seal` | `Sessions:323 Wiki:7` and `skills:(missing)` | `Sessions:323 Wiki:7` | `Sessions:323 Wiki:7` |
| this repository | three `(missing)` rows that belong to other projects | unchanged | unchanged |
| a copy at another path | its rows, and `skills:(missing)` | its rows | none, and nothing said — exit 0 |
| started as `SESSION-SEAL` | its rows, and `skills:(missing)` | its rows | none, and nothing said |

The author chose the second, and `~/.agentdocs.toml` for the home file — the name the repository's file has, with home where the root is — over `~/.config/agentdocs/config.toml` and over herdr's way, `%APPDATA%` on Windows. Every agent tool on this machine keeps its files directly under home: `~/.claude`, `~/.agents`, `~/.gemini`, `~/.copilot`.

**What a broken file does.** Three ways again, on a file whose first row says `walk = "tree"`: refusing to start printed the parser's message and exited 2, with no screen; a row printed the defaults with `config:(could not be read)` and the message under it, exit 0; keeping the rows that parse kept `Wiki:7` but said `source 1 (Sessions): unknown variant …`, without the line and column, and a quote left open dropped the whole file in that way as in the others. The author chose the row ([ADR-0012](../../adr/0012-config-files-sit-where-their-sources-do.md)). The row's name became the file's, `.agentdocs.toml`, which with the heading above it says which file it is; and what is printed under it became the parser's own drawing of the line, where the prototype had counted line and column itself.

**What the crates cost.** `serde`, its derive and `thiserror` were already being compiled for syntect and ratatui: nothing new. `toml` without its default features cost five compiled crates, eight packages in `Cargo.lock`, and 269 KB of the release binary ([[external-crates]]).

**What the parser accepts that might have been refused.** A file saved with a byte-order mark before its first line, and one with `\r\n` line ends, both read as they would without; nothing is done about either.

## Decisions

One record was written. [ADR-0012](../../adr/0012-config-files-sit-where-their-sources-do.md): a config file's place and name are what people write and keep, so they are not changed lightly; nobody would guess from the code why there are two files and why a typo drops a whole file; and the single file and the two other ways of breaking were real alternatives, built and run.

- **Chosen by the author**: a file at home and one at each project's root, `~/.agentdocs.toml` at home; a file that cannot be used is a row; no quizzes in M10; the terminal check after the last milestone.
- **Chosen by the assistant and reported** — with no quizzes, also every choice the author was not asked about: `[[source]]` tables of `name`, `path` and `walk`; the words for `walk` taken from the enum's names in kebab case; a relative path taken from home or from the root, `~/` from home, an absolute one as written; a key with no place refused; the added Sources after the built-in ones of their scope; each file read once, as the program starts; the row named after the file and placed at the end of its scope, worded `(invalid)` or, for a file that will not read, with the reason a Walk would give; the parser's words printed under it, through `printable`; the row selectable, after the last Source in number but where it is drawn for `j` and `k`; `order` as a list of names before any table, the rest keeping their places, an unknown name making the file unusable.

The existing records were checked against what M10 added. [ADR-0002](../../adr/0002-discovery-global-always-project-follows-cwd.md) rejected a config file as the way to find documentation, for an empty first screen, and left a door open for one that adds to defaults that already work; M10's is that, and with no file the screen is M9's. [ADR-0003](../../adr/0003-source-table-claude-first.md): a config file's rows are rows of the same table, a name, a path, a scope and a Walk, and adding a source is still adding a row — now one a user can write. [ADR-0005](../../adr/0005-sources-report-their-own-directory.md): a config row naming a directory another Source names is listed under both. [ADR-0009](../../adr/0009-unreadable-is-a-row-where-it-was-found.md) is what the broken file's row follows. [ADR-0011](../../adr/0011-changes-are-heard-not-polled.md): a config file's Sources are watched like any other; the file itself is not, below. `CONTEXT.md` gained **Config file**.

## What review caught

Two reviewers read the milestone once this log was written, each in a copy of the working tree: one the code, one this log with its pages and records. Every finding of the code's was reproduced with a test that failed before anything changed:

| finding | before | after |
|---|---|---|
| A Source's name went to the terminal as written. Until M10 every name was a word in `main.rs`; now a repository somebody else wrote can name one, and `printable`'s own promise — every field out of a file, name as well as description — did not reach it | a name holding a clear-screen escape and a carriage return: the escape reached stdout, and the return split the row in two; on the screen, a right-to-left override reached the Sources pane | `heading` and `failed` pass the name through `printable`, in both views; the built-in names are unchanged, and so is the listing |
| A link named `.agentdocs.toml` whose target is gone — what a dotfile manager leaves when the file it keeps is moved — was taken for no file: not found either way | the listing line for line as with no file at all, exit 0 | `.agentdocs.toml:(missing)`: not found is no file only when nothing at all is there, as a Walk lists a link whose target is gone |
| A config file's words are a note taller than the preview at ordinary sizes, and a drag held below one woke the loop every 30 ms with nothing to scroll | `autoscroll` due on every tick | nothing due: a note keeps no place, so it is as far as it goes |
| A tab in the line the parser quotes is dropped on its way to the terminal, but counted as a column by the parser | the `^` two columns right of what it marks | a space in its place |

Three more were left, below: a directory named `.agentdocs.toml` reported as `(permission denied)`, which is Windows' word for opening a directory; the `^` misplaced under Korean, which is the parser's own counting; and a Source named `""`. The code review also found that "wherever it is cloned" claimed too much — a clone outside the home directory has no project block — and the README and ADR-0012 now say *under the home directory*.

The documents' findings, all fixed: `Cargo.lock`'s growth counted in lines where packages were meant; three pages calling `listing::unused` the one `match` a new variant stops at, where since the system's words were put back there are three; the system's words said to be written up where the concept lives, and not yet written in [[result-and-errors]]; the final mutation row's tally, which did not add up as worded; ADR-0012 giving the parser's words as what a file that will not read is shown with; a script to count fixture names written as if it were a test; and *M10 asked nothing* beside a quiz that was put. One finding was not so: it read `Read` as `#[error("unreadable")]`, which is what one of the mutations writes — the copy it read is byte for byte the repository's, `transparent`.

What review checked and found sound: odd files — `~` alone, `~user`, `..`, `""` as a path, an `order` naming the other scope's Source, duplicates in `order`, a 2 MB line, BOM and CRLF; the project root never being home; `j` and `k` through both scopes' rows and stopping at the ends; a reload with the config row selected; clicks, Tab and Page Down on it; copying its words; the carry-over from every earlier log, item by item; and every count, sample and tally in this log against its source.
